# 👥 HR Analytics Dashboard (Tableau)

An interactive **HR Analytics Dashboard** built using **Tableau** to analyze employee demographics, job roles, salaries, education levels, and hiring trends.  
This dashboard helps HR teams understand workforce structure, identify hiring patterns, evaluate salary distribution, and support data-driven HR decisions.

## 🎯 Project Overview

This Tableau project explores HR-related data and provides clear insights into:

- Gender distribution across the organization  
- Job title-wise employee count  
- Age distribution among employees  
- Salary analysis by job title and education  
- Employee joining trend across years  
- Identification of job roles with the highest number of employees  
- Individual employee salary comparison  

The dashboard is fully interactive and designed for HR managers, talent acquisition teams, and management teams to make workforce decisions quickly.

## 🖼 Dashboard Preview – Key Visuals

### ✔ Job Title Distribution

### ✔ Gender Ratio  
Pie chart showing male vs female employee distribution.

### ✔ Age Distribution  
Histogram showing age spread of employees grouped into bins.

### ✔ Salary Comparison (Employee-wise)

### ✔ Joining Trend Over Years
